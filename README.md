## Sobre o Projeto
Este projeto consiste em um script simples e direto em Python criado para facilitar o cálculo de médias aritméticas de notas. O programa foi estruturado com foco na experiência do usuário via terminal, permitindo inserir uma quantidade flexível de notas, tratando erros de digitação e informando o resultado final junto com a situação de aprovação.

## Funcionalidades
* **Entrada dinâmica:** Adicione quantas notas forem necessárias utilizando um laço de repetição contínuo.
* **Validação de notas:** Garante que apenas valores numéricos válidos entre `0` e `10` sejam computados.
* **Tratamento de exceções:** Impede que o programa quebre caso o usuário insira letras ou caracteres inválidos por engano.
* **Avaliação de status:** Calcula a média final com duas casas decimais e retorna automaticamente se o aluno foi Aprovado ou Reprovado (baseado na média 6.0).

## Tecnologias Utilizadas
* **Python 3** (Lógica principal utilizando estruturas condicionais, listas e tratamento de exceções com `try/except`).
* **Git e GitHub** (Controle de versão).
